# 그림 스토리 단어 미션 — 소스 구조

배포되는 게임은 `word-game/index.html` 한 파일이에요 (GitHub Pages: `https://<계정>.github.io/<저장소>/word-game/`).
이 파일은 **빌드 결과**라서 직접 고치지 않고, `app/src`를 고친 뒤 빌드해요.

```
npm install                          # 테스트용 jsdom 받기 (게임 실행에는 필요 없음)
SITE_KEY=<공유 링크> npm run build    # app/src → 잠근 word-game/index.html
npm test                             # 빌드가 최신인지 + 회귀 테스트 (열쇠 없이 돼요)
```

### 링크가 있어야 열리는 사이트

사이트에 올라가는 `word-game/index.html`은 게임 전체를 AES-GCM으로 잠근 페이지(`app/src/lock.html`)예요.
공유 링크 `…/word-game/#k=<열쇠 43글자>`의 `#` 뒤가 열쇠이고, 이 부분은 브라우저가 서버로 보내지 않아요.
열쇠가 없거나 틀리면 잠금 화면만 보이고, 검색 엔진에는 나오지 않게(`noindex`) 해 두었어요. 한 번 연 기기는 열쇠를 기억해서 주소만으로도 열려요.

- 열쇠는 **저장소에 넣지 않아요**. 빌드할 때 `SITE_KEY`(링크 전체나 `#` 뒤 열쇠) 또는 `app/.site-key` 파일(`.gitignore`에 있음)에서 읽어요.
- `node app/build.cjs --link`: 지금 열쇠로 공유 링크 보기. `--new-key`: 새 열쇠로 바꾸기 (예전 링크는 더 이상 안 열려요).
- 주인 단어장(교재 단어로 만든 이야기 단어장)은 `app/decks.enc`에 같은 열쇠로 잠가 두고, 잠근 게임 안에만 넣어요. 게임을 열면 단어장 보관함에 들어가요.
  고칠 때: `--decks-out <폴더>`로 풀고, 고친 뒤 `--decks-in <폴더>`로 다시 잠가요.
- 막아 주는 것은 *사이트에서 게임을 여는 것*이에요. 저장소가 공개라서 `app/src`의 코드는 GitHub에서 누구나 볼 수 있어요.
  코드까지 숨기려면 저장소를 비공개로 바꿔야 하는데, 무료 계정에서는 비공개 저장소의 GitHub Pages가 꺼져요 (GitHub Pro 이상 필요).

### 인터넷 없이 쓰기

- 게임은 이 사이트의 파일만 불러요(글꼴도 `word-game/fonts/`). 다른 곳에 연결하는 것은 이야기 AI 모델을 처음 한 번 받을 때(Hugging Face·GitHub)뿐이고, WebLLM이 받은 모델을 브라우저에 저장해요.
- `word-game/sw.js`가 페이지는 인터넷 먼저(안 되면 저장해 둔 판), 이 폴더의 파일은 저장해 둔 것 먼저 써요. 다른 사이트로 가는 요청은 건드리지 않아요.
- 만들기 화면의 **인터넷 없이 쓰게 준비하기**: 사진 읽기·목소리·글꼴·AI 실행(`llm/`) 파일(약 58MB)과 이야기 AI(약 3GB)를 한 번에 받아 둬요. 처음 열 때는 작은 핵심만 저장해요.
- 이야기·미션을 열면 올라가 있던 이야기 AI를 내려놓아요(만들거나 받는 중이면 그대로). 메모리가 작은 휴대폰에서 휴대폰 목소리가 소리를 낼 수 있게요. 다음에 만들 때는 저장해 둔 모델을 다시 올려요.
- 아직 이야기 AI를 안 받았는데 모바일 데이터(또는 데이터 절약 모드)면 게임 만들기는 AI 없이 앱 문장으로 만들고, 준비하기 단추는 한 번 더 눌러야 받아요.
- `word-game/` 안의 파일(`index.html` 말고)을 바꾸면 `word-game/sw.js`의 `VERSION`을 바꿔요. `npm test`가 새 값을 알려 줘요.

## 사진 단어장의 이야기 문장 늘리기

Claude 없이 만드는 이야기는 `08-story-gen.js`의 표 두 개로 문장을 골라요.

- `SEM`: 뜻 갈래별 장면 문장. 한 줄이 `[뜻 열쇠말 정규식, { n: 명사, v: 동사, a: 형용사, d: 부사 문장 틀 }, 그림]`이에요.
  열쇠말은 낱말 첫머리에서만 찾아요(‘침착한’ 속 ‘착한’은 안 맞음). 위에 있는 줄이 먼저예요.
- `ST_GEN`: 갈래에 없는 뜻에 쓰는 품사·갈래별 기본 문장.

문장 틀 토큰: `{H}` 주인공 · `{F}` 친구 · `{V}` 말썽꾼 · `{P}` 장소 · `{G}` 찾는 물건 · `{E}` 사건 (`{H:은}`처럼 쓰면 받침에 맞는 조사),
`{W}` 단어 자리(`{W:을}` 뜻 + 조사), 동사 `{W:past}` `{W:ki}` `{W:go}` `{W:ryeo}` `{W:ryeodaga}` `{W:ra}`, 형용사 `{W:attr}` `{W:pp}` `{W:ge}`.
틀을 더하면 `npm test`가 조사·남은 기호·반복을 확인해요.

## 저작권

- 기본 단어장(창작 데모 · 동화 7편)은 단어 선택, 뜻, 예문, 암기 팁, 자막, 그림을 모두 새로 만든 것이에요. 교재 내용은 들어 있지 않아요.
- 사진으로 만든 단어장은 그 사람의 브라우저(`localStorage`)에만 저장되고 서버로 보내지 않아요. 앱은 사진 화면과 완성 화면에서 '직접 가진 교재로 혼자 공부할 때만 쓰고, 만든 단어장을 나누거나 올리지 말라'고 안내해요.
- 이 저장소에는 교재 사진이나 교재에서 옮긴 단어 목록·뜻·예문을 커밋하지 마세요. 테스트에도 일반 사전 뜻만 써요.
- 함께 배포하는 글자 인식·음성 도구와 단어 목록의 라이선스는 `word-game/tts/NOTICE.txt`에 정리돼 있어요.
