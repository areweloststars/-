  - 규칙 글을 나눴어요 (작가·설계자·편집자·고치는 이 + 공통 이야기 규칙 + 답 꼴 text/json). 뜻 말 보기는 꼴과 상관없이 "칭찬했어요 ✓ / 칭찬(을 받았어요) ✗"처럼 적어요. 보기 이야기는 데이터 하나로 두 꼴을 만들어요.

### 올리기와 재기 (사용자가 대시보드에 붙여 넣음, 이 세션 네트워크는 '전체')

- **gpt-oss-120b, 생각 low, 첫 규칙 글, 30편**: 형식 **8/30**, 한 편 11초.
  - 15편은 앱이 못 읽었어요: 14편은 `**제목**`을 따로 한 줄에 쓰고 줄마다 번호를 붙인 꼴, 1편은 `!!!!…`만 나온 망가진 답 → 서버가 앱이 읽는 꼴로 고치게 했어요 (같은 답을 다시 읽으면 12/30, 나머지는 읽히자 뜻 꼴 등 다른 규칙에 걸림).
